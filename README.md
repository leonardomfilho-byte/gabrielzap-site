# gabrielzap.com.br

Landing page do Gabriel (cobrança automática por WhatsApp). Página estática,
publicada pelo GitHub Pages com domínio próprio (arquivo `CNAME`).

Fica separada do repositório do sistema de propósito: o site continua no ar
mesmo quando o Google Cloud do sistema cai, e este repositório não carrega o
histórico (nem os segredos antigos) do código do Gabriel.

- `index.html` — a página inteira (HTML + CSS + JS, sem build).
- Os botões "Entrar" e "Começar" apontam para o sistema. Trocar para
  `https://app.gabrielzap.com.br` quando esse endereço existir.
